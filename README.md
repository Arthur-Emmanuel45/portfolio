
# Portfolio Project

This is a personal portfolio website designed to showcase education, work experience, and projects. The site is built using HTML, CSS, and JavaScript, and is organized into several sections for easy navigation.

## Features
- **Home Page**: Introduction and overview.
- **Education**: Academic background and achievements.
- **Work Experience**: Professional history and roles.
- **Projects**: Highlights of key projects with images.

## File Structure
```
├── education.html
├── home_script.js
├── index.html
├── project.html
├── README.md
├── work_experience.html
├── image/
│   ├── backgrounds/
│   └── project_pics/
└── styles/
	├── education_styles.css
	├── home_styles.css
	├── project_styles.css
	└── work_experience-styles.css
```

## How to Use
1. Clone or download the repository.
2. Open `index.html` in your web browser to view the home page.
3. Navigate to other sections using the provided links.
